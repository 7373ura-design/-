## 申し送り

- **QRコードのリンク先は暫定**（https://zenjapanesemassage.com/ ）。ボンダイ店専用LPのURL確定後、QR画像の作り直しが必要です。
- 入稿時はロゴをラスター画像ではなくベクター（AI/EPS/SVG）に差し替えてください。今回の案はレイアウト検討用です。
- 右パネル（8m）は文字量に対して横幅に余白が出ます。ロゴを繰り返す／端に電話番号・営業時間を入れる、などの案も検討可能です。
