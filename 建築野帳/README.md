# 建築野帳（建築ノート）

将来建築士を目指すユーザーのための、建築見学の記録・分析ツール。大学や就職の面接で「自分の言葉で語れる」深さを引き出すことを目的に設計。

## 現状

- `kenchiku-yachou.html` が本体（単一HTMLファイル、外部依存なし、Google Fontsのみ読み込み）
- Claude Artifact として公開済み: https://claude.ai/code/artifact/d4c2b168-949d-4b61-87fc-cd513e11962e
  - `claude.ai` 上でこのURLを開くと動作する
  - データ（記録テキスト・写真）はブラウザの IndexedDB にのみ保存され、外部送信なし
  - `downloads` capability を宣言済み。「バックアップ」からテキスト記録のみ JSON 書き出し可（写真は16MB上限の関係で対象外、写真は各ブラウザのローカル保存のみ）
- **まだユーザーの実際の写真は1枚も取り込まれていない。** ユーザーはローカルPCの「ピクチャ／建築」フォルダに約100枚の建築写真を保有しており、これをこれから取り込む必要がある

## 機能概要

- 写真を複数枚まとめて取り込むと、1枚＝1シート（記録カード）が自動生成される
- 各シートは建築図面の「表題欄」を模したレイアウト：建物名／設計者／所在地／用途／構造種別／竣工年／訪問日
- 分析メモは7設問固定（コード内 `ANALYSIS_FIELDS` 参照）：
  1. 第一印象
  2. 構造・技術的見どころ
  3. 空間構成・動線
  4. 素材と光
  5. 設計意図・文脈
  6. 自分との接続
  7. 比較・参照
- 「一言サマリー」欄＝面接の最初の一言用
- ☆面接候補フラグ → 「面接対策」ビューに一覧＋印刷対応
- 完成度％、ステータス（未記入／下書き／完成）を自動判定
- タグ、検索、ステータス/面接候補フィルタ、並び替え

## デザイントークン（変更する場合は踏襲すること）

- 配色: `--paper #EFEAE0` `--ink #23241F` `--graphite #6B6A5E` `--line #CDC6B4` `--accent #C1442D`（ダークモード値はCSS内 `:root[data-theme]` 参照）
- フォント: 見出し=Zen Old Mincho／本文=Zen Kaku Gothic New／ラベル数値=JetBrains Mono
- モチーフ: 建築図面の表題欄・シート番号（"No. 001" 形式）

## 経緯（このセッションで起きたこと）

ユーザーが「ピクチャの建築フォルダの画像を全部取り込んで」と依頼したが、このセッションは Anthropic クラウド上のリモート実行環境（`environment_kind: anthropic_cloud`）で動いており、ユーザーのローカルPCのファイルシステムには物理的にアクセスできないことが判明。ユーザーはローカル環境（PC上で直接動くClaude Code CLIなど）に切り替えて作業を続けたいとのことで、引き継ぎ用にこのファイルをリポジトリにコミットした。

4. 完了後、必要であれば Claude Artifact 側（上記URL）にも同じ内容を反映するか、ユーザーに再度ブラウザから開いてもらい取り込んでもらう
