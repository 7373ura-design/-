## 張り子のだるまサンタ
- [ ] 水風船 … 型にする。ふくらませて上に新聞を貼る（Daiso）
- [ ] ボンド（PVA）… 水と1：1で混ぜて、新聞を貼るのりにする（Daiso。なければ Kmart / Officeworks）
- [ ] アクリル絵の具 … 体を赤、顔を白に塗る。しめ飾りの紙ひもの色付けにも使う（Daiso）
- [ ] 筆 … 色を塗る（Daiso）
- [ ] 小さいポンポン … サンタの帽子の先（Daiso）
- [ ] Poscaペン（Daisoならペイントマーカー）… 眉と目の輪郭を描く（Daiso。なければ Kmart / Officeworks）

## しめ飾り（紙ひもで自分で作る）
- [ ] 紙ひも（paper raffia）… しめ縄の本体（Daiso。なければ Spotlight）
- [ ] 造花（松・赤い実など）… 飾りの部分（Daiso。なければ Spotlight）
- [ ] グルーガン … 造花を付ける（Daiso。なければ Kmart）
- 絵の具と筆は、だるまサンタと同じものを使う
