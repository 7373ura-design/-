# NAMI STUDIO｜インスタの進め方と、Matsuri（12/6）までの計画

2026年11月24日　浦 七海

---

## 1. インスタの目的とターゲット
| | 内容 |
|---|---|
| **目的** | 新しい人を集めることより、NAMIを知った人に「この人なら安心して任せられる」と思ってもらうこと |
| **ターゲット** | シドニーの40〜50代の持ち家の人（これから家を買う人、買った後の人も含む） |
| **NAMIの軸** | 家を作るだけでなく、そこでの暮らし全体をデザインする |
| **アカウントの役割** | デザインして終わりではなく、実際に住むときの困りごとまで解決する。すでにいるお客さんには「住んだ後も頼れる」、NAMIを知らない人には「この投稿、助かる」と思ってもらう |

**なぜこう決めたか：** 40〜50代はインスタでデザイナーを探すより、紹介やGoogleで見つけて、インスタで「この人は大丈夫か」を確かめることが多い。だからインスタは「人を集める場所」より「信用してもらう場所」にする。

## 2. 毎回の投稿で伝えること
**信用・実績・安心・安全** の4つのどれかが、必ず伝わるようにする。

| 価値 | 見せ方 |
|---|---|
| 信用 | 顔と人柄、資格、Japan Homes とのつながり |
| 実績 | 施工事例、提案の事例、ビフォーアフター |
| 安心 | 進め方、お金の考え方、住んだ後までのサポート |
| 安全 | 素材の選び方、資格のある業者が施工すること |

**判断の基準：** 「40〜50代の家主が喜ぶか」「家の中の悩みに答えているか」

## 3. 投稿の3本の柱
| 柱 | 割合 | 中身 |
|---|---|---|
| ① デザインと実績 | 4割 | 施工事例、提案の事例、素材の選び方、「家づくりは高い？」、家の価値が上がるデザイン |
| ② 暮らしの知恵 | 4割 | 収納、住んだ後に揃えるもの（器・香り・家具）、日本の知恵、季節の文化 |
| ③ 七海という人 | 2割 | 日本で育ったこと、資格、現場の様子、Japan Homes との仕事 |

## 4. アイデアと評価
| アイデア | 評価 | 理由 |
|---|---|---|
| 住んだ後まで暮らしをサポートする | ◎ | 他のデザイナーとの一番の違い |
| 家を買うハードルを下げる（家づくりは高い？） | ◎ | 依頼をためらう一番の理由に答えられる |
| 素材の選び方 | ◎ | 40〜50代が一番迷うところ。専門性が伝わる |
| 家の価値が上がるデザイン | ◎ | 不動産の資格を生かせる強み |
| 香り・家具・皿やコップまで統一したい人向けの色のサンプル | ◎ | 「ここまでしてくれる」という安心と信用になる。サービスにもできる |
| 簡単にできる収納（Daiso・無印・Bunnings など） | ○ | 住むときの困りごとを解決できる |
| 日本の知恵（もったいない、便利グッズなど） | ○ | 日本人が話す意味がある。たまに出す |
| 季節の文化（しめ飾りなど） | ○ | 季節ごとに1〜2本まで |
| 賃貸向けの簡単リノベ | △ | お客さんになりにくい層が中心 |
| 料理グッズ | × | インテリアと関係が薄い |

## 5. Matsuri（12/6）までのスケジュール
| 日付 | やること |
|---|---|
| 11/24 | 名刺・チラシを発注（済み） |
| **11/25** | 名刺・チラシを受け取る ／ 買い出し ／ Googleフォーム（応募用）を作る ／ インスタに4本投稿（What is NAMI?・Why Japandi? を直して再投稿、Our Work & How We Work を新しく投稿、Matsuri の告知を Japan Homes とコラボ投稿）。上の3本をプロフィールに固定する |
| 11/27 | 張り子のだるまサンタを作り始める（乾くまで1〜2日） |
| 11/28 | しめ飾りを作る |
| 11/29 | だるまサンタを仕上げる ／ うちわを作る |
| 11/30 | 投稿：張り子のだるまサンタ（日本のクリスマス＝大事な人を思う日） |
| 12/1 | 投稿：しめ飾りの意味 ／ ポップと応募用紙を印刷 |
| 12/3 | 投稿：家づくりは高い？ |
| 12/4 | 投稿：家の価値が上がるデザイン ／ 持ち物チェック、ブースの並べ方と英語の声かけを練習 |
| 12/5 | ストーリー「See you tomorrow」 |
| **12/6** | **Matsuri 当日**（ストーリーを3〜5回） |

**季節の投稿は2つだけ**（どちらもブースに飾る）

- **張り子のだるまサンタ：** 日本の伝統技法「張り子」で、だるまをサンタにする。日本のクリスマスは宗教ではなく「大事な人を思って小さな特別を作る日」として紹介する
- **しめ飾り：** 日本の玄関とお正月の文化を紹介する

**ブースの応募の入口：** ポップのQR（Googleフォーム）がメイン、紙の応募用紙が予備。イベント限定なのでプロフィールには書かない

## 7. Matsuriの後
- 12/6 夜：紙の応募をスプレッドシートに入力 → 12/8 応募者全員にお礼メール → 12/9〜19 モニターを決める
- モニターの家は、最初の打ち合わせから許可を取って記録する（一番大事な実績になる）
- インスタを週2〜3本で続ける
- インスタ以外：Googleビジネスプロフィール、サイトの公開、Facebook、紹介ルート（Japan Homes、不動産会社、建築業者）
