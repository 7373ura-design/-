## 4. 応募の流れ（こちらから連絡する方式）

1. ブースで応募用紙を書いてもらう（**メール必須・電話は任意**）
2. 書けない人・急いでいる人には、フォームのQRを読んでもらう
3. その日の夜：紙の内容をスプレッドシートに入力する（フォームの回答と同じシートへ）
4. **48時間以内**：全員にお礼メール（`メール文面.md` の①）
5. 1週間以内：応募内容を読み、候補の人に「お話ししませんか」メール（②）
6. 12月中：モニター決定（③）／外れた人には特典の案内（④）
7. ニュースレターOKの人には、月1回DIYメールを送る（2027年から）

> 応募用紙の同意欄は2つに分けてあります。①モニターの連絡（必須）②ニュースレター（任意）。
> オーストラリアでは宣伝メールに受信の同意が必要なので、②にチェックがない人には宣伝メールを送らないでください。

### 応募用紙（完成）
- `print/entry-card_A4x4.pdf`：A4に4枚。家のプリンターで印刷して切ればOK（印刷会社に出さなくていい）
- 項目：名前・メール・電話（任意）・Instagram・住んでいる地域・家の種類・持ち家か賃貸か・変えたい場所・始めたい時期・どんな家にしたいか・一番変えたいこと・同意2つ
- 40枚（A4用紙10枚）あれば十分です

### Googleフォーム（スクリプトで作る）
`google-form/create_form.gs` をGoogle Apps Scriptに貼って ▶ 実行するだけで、次の2つが自動で作られます。
- 応募用紙と同じ項目のフォーム（「どこでNAMIを知りましたか」も追加）
- 回答がたまるスプレッドシート「NAMI — Founding Monitors 応募リスト」

使い方はファイルの冒頭に書いてあります。フォームのURLが出たら、InstagramのプロフィールリンクとQRに使います。

## 7. 当日の声かけの流れ

## 9. Instagramを見る件について

今このセッションには、あなたのパソコンがつながっていません。なので、あなたの画面で開いたInstagramをこちらから見ることはまだできません。

**見られるようにする方法**
1. パソコンでClaudeデスクトップアプリを開く
2. 設定 → Claude Code → Remote Control で、フォルダを1つ共有する
3. その状態で「つないだ」と教えてもらえれば、こちらから接続をリクエストします
4. Instagramへのログインはあなたがブラウザで済ませてください（パスワードを私に教える必要はありません）

**つながらなくても今できること**
- インサイト（リーチ・保存数・フォロワーの増え方）の **スクリーンショット** を送ってもらえれば、分析して次の投稿に反映できます
- リールは動画なので、つながっても私が見られるのはほぼキャプションとサムネイルです。参考リールは、あなたのメモ（何が良いか）があれば十分に使えます
